Features Implementation ##

1. Sorting Algorithms ###

Supported Algorithms: 1. Bubble Sort - Time Complexity: O(n²) average/worst, O(n) best - Space Complexity: O(1) - Stable: Yes 2. Selection Sort - Time Complexity: O(n²) all cases - Space Complexity: O(1) - Stable: No 3. Insertion Sort - Time Complexity: O(n²) average/worst, O(n) best - Space Complexity: O(1) - Stable: Yes 4. Heap Sort - Time Complexity: O(n log n) all cases - Space Complexity: O(1) - Stable: No 5. Merge Sort - Time Complexity: O(n log n) all cases - Space Complexity: O(n) - Stable: Yes 6. Quick Sort - Time Complexity: O(n log n) average, O(n²) worst - Space Complexity: O(log n) - Stable: No ###

Features: - Interactive Controls: Play, Pause, Reset buttons - Speed Control: Enhanced slider with range 1-200 for ultra-fast animations - Real-time Statistics: Comparisons and swaps counter - Input Methods: Random generation or manual input - Visual Feedback: Color-coded bars showing comparisons and sorted elements - Responsive Design: Adapts to different screen sizes ##

2. Graph Algorithms ###

Supported Algorithms: 1. Breadth-First Search (BFS) - Use Case: Level-order traversal, shortest path in unweighted graphs - Time Complexity: O(V + E) - Space Complexity: O(V) 2. Depth-First Search (DFS) - Use Case: Path finding, cycle detection - Time Complexity: O(V + E) - Space Complexity: O(V) 3. Dijkstra's Algorithm - Use Case: Shortest path in weighted graphs (positive weights) - Time Complexity: O((V + E) log V) - Space Complexity: O(V) 4. Prim's Algorithm - Use Case: Minimum Spanning Tree - Time Complexity: O(E log V) - Space Complexity: O(V) ###

Features: - Interactive Graph Input: Manual entry or random graph generation - Visual Animation: Step-by-step algorithm execution - Color-coded Visualization: - Green: Visited nodes - Orange: Frontier/Queue nodes - Red: Ignored/Rejected nodes - Gray: Unvisited nodes - Control System: Play, Pause, Reset functionality - Fixed Animation Speed: Consistent timing for graph algorithms - Canvas Management: Proper cleanup to prevent visual artifacts #
