Topological Sort (Kahn's algorithm)

A topological order lists the nodes of a directed graph so that every arrow points forward: for each arrow U to V, U comes before V. Kahn's algorithm builds one by repeatedly placing a node that no remaining arrow points at.

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • Course plans: take a course only after its prerequisites
  • Build systems: compile a file only after what it depends on
  • Spreadsheets: recalculate a cell only after the cells it reads
  • Package managers: install dependencies first

If the arrows form a cycle, no order exists, and the run stops and names the nodes that could never be placed.
