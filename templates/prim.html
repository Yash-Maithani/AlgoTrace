Prim's Algorithm

Prim builds a minimum spanning tree: the cheapest set of edges that joins every node without a loop.

It grows one tree from the start node, always adding the cheapest edge that reaches a node not yet in the tree.

The edges waiting to be tried sit in a heap, so the cheapest one is always on top.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • Connecting buildings with the least cable, or towns with the least road.
  • Any network that must reach everywhere as cheaply as possible.
