Prim's Algorithm

Prim's algorithm is used to find the minimum spanning tree of a connected, undirected graph. It starts with a single vertex and grows the MST by adding the cheapest edge that connects a vertex in the tree to a vertex outside the tree.

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • Network design
  • Circuit design
  • Clustering algorithms
  • Image segmentation

Note: For Prim's algorithm, the graph input should include edge weights. Example format:

{
   "5 6
    A D 11
    A C 7
    B D 11
    B E 7
    A E 9
    C E 7
    A"
