Bellman-Ford Algorithm

The Bellman-Ford algorithm finds the shortest paths from a single source vertex to all other vertices in a weighted graph. Unlike Dijkstra's algorithm, it can handle negative edge weights and detect negative cycles.

Time Complexity: O(VE) where V is the number of vertices and E is the number of edges

Space Complexity: O(V)

Use Cases:

  • Shortest path with negative weights
  • Negative cycle detection
  • Currency arbitrage detection
  • Network routing protocols

Note: edges are read as undirected, so a single negative edge is itself a negative cycle and will be reported as one. Example input:

5 6
A B 6
A C 7
B C 8
B D 5
C E 9
D E 2
A
