Depth-First Search (DFS)

DFS is a graph traversal algorithm that explores as far as possible along each branch before backtracking.

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • Topological sorting
  • Cycle detection
  • Maze solving
  • Game tree exploration
