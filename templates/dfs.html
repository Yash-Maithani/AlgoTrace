Depth-First Search (DFS)

DFS follows one path as far as it can go, then backs up to the last place with a choice it has not tried.

It keeps the nodes waiting their turn on a stack: last in, first out.

It reaches every node the start can reach, but not by the shortest route.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • Exploring every room of a maze, or every page a website links to.
  • Spotting a cycle: a path that leads back to a node still on the stack.
  • The basis of many other graph algorithms, including one way to order tasks.
