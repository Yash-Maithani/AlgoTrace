Breadth-First Search (BFS)

BFS is a graph traversal algorithm that explores all vertices at the present depth before moving on to vertices at the next depth level.

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • Shortest path finding in unweighted graphs
  • Web crawling
  • Social networking (finding connections)
  • GPS navigation systems
