Breadth-First Search (BFS)

BFS starts at one node and visits everything one edge away, then everything two edges away, and so on, ring by ring.

It keeps the nodes waiting their turn in a queue: first in, first out.

Because it goes ring by ring, the first time it reaches a node is by the fewest edges possible.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • Fewest hops between two places when every hop counts the same, such as degrees of separation in a friendship network.
  • Checking which nodes can be reached from a starting point at all.
  • Finding the shortest way through a maze drawn on a grid of equal steps.
