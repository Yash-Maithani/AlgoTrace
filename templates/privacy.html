Privacy Policy

Algorithm Visualizer is a student project built to teach sorting and graph algorithms. This page describes what the application does with information you enter into it.

What is collected

Nothing. There are no accounts, no sign in, no analytics, no advertising and no third party trackers. The application does not set cookies, and it does not use session storage or IndexedDB. The only thing it keeps in your browser is the two preferences listed next.

What is stored in your browser

Two small preferences, in your browser's local storage for this site. They stay on your device. They are not sent to the server with any request, and nothing on the server reads or records them.

Local storage keys this site sets
Key Value Set when What it does
theme light or dark You press the light and dark button in the header. Opens every page in the theme you chose. Until you press the button nothing is stored and the page follows your system setting.
pbl2.codeLanguage pseudocode, python, c, cpp or java You choose a language on a Code tab or on the Home code card. Shows code in that language on every page. Until you choose, nothing is stored and the code is shown in Python.

That is the complete list. If your browser blocks local storage, as a private window often does, the site still works and simply does not remember the choice.

How to clear them

  • Clear this site's data in your browser: in Chrome and Edge, Settings, then Privacy and security, then Site settings, then View permissions and data stored across sites, and delete this site. In Firefox, Settings, then Privacy and Security, then Cookies and Site Data, then Manage Data. In Safari, Settings, then Privacy, then Manage Website Data.
  • Or in the browser's developer tools console on this site, run localStorage.clear().
  • Or choose a different theme or language: the new choice replaces the old one.

After clearing, the next visit starts from your system's theme and Python code.

What you type into the page

Array values, graph definitions and the start node you enter are sent to the server so the algorithm can be run and the animation steps calculated. They are used to build that one response and are not written to a database, a log file or any storage that outlives the request.

Requests to other services

Two resources are loaded from outside this site: the Space Grotesk, Fira Sans and Fira Code typefaces from Google Fonts, and the D3 charting library from its public CDN on the graph pages. Loading those files tells the services involved your IP address and browser version, as any web request does. No information you enter into this application is sent to them.

Running it yourself

The source is a Flask application that can be run on your own machine. When it runs locally, requests never leave your computer apart from the font and library files described above.

Changes

If this project later adds anything that stores or shares information, this page will be updated to say so before that feature ships.
