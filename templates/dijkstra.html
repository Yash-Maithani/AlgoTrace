Dijkstra's Algorithm

Dijkstra's algorithm is used to find the shortest path between nodes in a graph with non-negative edge weights.

Time Complexity: O((V + E)logV) where V is the number of vertices and E is the number of edges

Space Complexity: O(V)

Use Cases:

  • GPS navigation systems
  • Network routing protocols
  • Traffic management systems
  • Game pathfinding

Note: For Dijkstra's algorithm, the graph input should include edge weights. Example format:

{
    'A': {'B': 4, 'C': 2},
    'B': {'A': 4, 'D': 3},
    'C': {'A': 2, 'D': 1},
    'D': {'B': 3, 'C': 1}
}
