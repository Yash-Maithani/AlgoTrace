Dijkstra's Algorithm

Dijkstra finds the cheapest route from one start node to every other node, where each edge has a cost.

It always settles the nearest node it has not settled yet, then checks whether going through it makes any neighbour cheaper.

It needs every edge cost to be zero or more; a negative cost can fool it.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • Cheapest or shortest routes when the roads have lengths, as in a route planner.
  • Routing data through a network where each link has a cost.
