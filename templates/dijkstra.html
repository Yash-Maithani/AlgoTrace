Dijkstra's Algorithm

Dijkstra's algorithm is used to find the shortest path between nodes in a graph with non-negative edge weights.

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • GPS navigation systems
  • Network routing protocols
  • Traffic management systems
  • Game pathfinding

Note: For Dijkstra's algorithm, the graph input must carry edge weights. The format guide above the input box shows the usual edge list; a JSON object of neighbours and weights is accepted as well, and has to use double quotes. Either of these runs as written:

5 7
A B 4
A C 2
B C 5
B D 10
C D 3
C E 7
D E 6
A
{
    "A": {"B": 4, "C": 2},
    "B": {"A": 4, "D": 3},
    "C": {"A": 2, "D": 1},
    "D": {"B": 3, "C": 1}
}
