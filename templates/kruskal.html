Kruskal's Algorithm - Animated MST Visualizer

Kruskal's algorithm constructs a Minimum Spanning Tree (MST) by greedily selecting the smallest weighted edges that don't create cycles.

Time Complexity: O(E log E) where E is the number of edges

Space Complexity: O(V + E) where V is the number of vertices

Real-world Applications:

  • Network design optimization
  • Circuit design and wiring
  • Cluster analysis in data science
  • Image segmentation processing
  • Road network planning

Input Format (Undirected Weighted Graph):

n m
U1 V1 W1
U2 V2 W2
...
Um Vm Wm

n: Number of nodes
m: Number of edges
Each line: undirected edge between Ui and Vi with weight Wi
Node labels: uppercase letters (A, B, C, ...)

Example:

5 7
A B 2
A C 3
B C 1
B D 4
C D 5
C E 6
D E 7
