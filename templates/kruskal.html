Kruskal's Algorithm

Kruskal builds a minimum spanning tree: the cheapest set of edges that joins every node without a loop. It works from the edges rather than from a start node.

It sorts every edge by cost and takes them cheapest first, skipping any edge whose two ends are already joined, because that edge would close a loop.

If the graph is in separate pieces, it builds one tree per piece.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • Connecting everything as cheaply as possible, the same job as Prim.
  • Grouping points into clusters, by stopping before the most expensive joins.
