Floyd-Warshall Algorithm

Floyd-Warshall finds the shortest distance between every pair of nodes at once, in a table.

For each node in turn it asks, for every pair: is going through this node shorter than the best route so far?

Negative edge costs are fine, as long as no loop adds up to less than zero.

How long it takes and how much memory it needs, for the code on this site, are in the Complexity tab of the Learn panel, with the reason for each figure.

Good for

  • A full table of distances between every pair of places, such as a mileage chart.
  • Small, dense graphs, where answering every pair at once is worth it.
