Floyd-Warshall Algorithm

The Floyd-Warshall algorithm finds shortest paths between all pairs of nodes in a weighted graph (with positive or negative edge weights, but no negative cycles).

Time and space complexity for this implementation are in the Complexity tab of the Learn panel above, with the reason for each figure.

Use Cases:

  • All-pairs shortest path in networks
  • Transitive closure of directed graphs
  • Routing protocols
